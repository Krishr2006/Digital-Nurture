## API Debugging

API debugging is the process of checking whether requests are sent correctly and responses are received successfully.

---

## Network Tab

The Network tab displays:

- Request URL
- Request Method
- Status Code
- Response Body
- Response Headers
- Request Time

---

## Common HTTP Status Codes

200 - OK

201 - Created

400 - Bad Request

401 - Unauthorized

403 - Forbidden

404 - Not Found

500 - Internal Server Error
