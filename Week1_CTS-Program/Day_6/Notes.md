# Day 6 - Logging Framework

## What is Logging?

Logging is the process of recording events, messages, warnings, and errors that occur while an application is running.

Logs help developers:

- Debug applications
- Monitor application behavior
- Identify errors
- Track application flow

---

## Why Logging is Important?

Instead of using:

```java
System.out.println("Application Started");
```

## Developers use logging frameworks because they provide :

- Better debugging
- Log levels
- Log management
- Production monitoring
- Common Log Levels

## INFO :

Used to record normal application events.

Example:
- Application Started

## WARNING :

Used to indicate potential problems.

Example:
- Low Memory Warning

## SEVERE / ERROR :

Used to record serious errors.

Example:

- Database Connection Failed

## Advantages of Logging :

- Easier debugging
- Better monitoring
- Production support
- Error tracking
