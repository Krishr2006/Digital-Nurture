## Docker

Docker is a platform used to build, package and run applications inside containers.

---

## Docker Image

A Docker Image is a blueprint used to create containers.

---

## Docker Container

A Docker Container is a running instance of a Docker Image.

---

## Docker Hub

Docker Hub is an online repository used to store and download Docker Images.

---

## Common Docker Commands

docker --version

docker pull hello-world

docker images
